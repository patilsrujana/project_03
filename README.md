MINOR PROJECT 03

About the Project :
  This project is a beginner-friendly smartwatch landing page developed using HTML, CSS, and JavaScript. 
  It presents smartwatch products with an attractive layout and simple interactive features.

Objectives :
  Create a user-friendly smartwatch product webpage.
  Display smartwatch varieties and their details.
  Use CSS to improve the design and layout.
  Use JavaScript to add interactive functionality.

Technologies Used :
  HTML5: Creates the structure of the webpage.
  CSS3: Styles the webpage, including colors, spacing, layout, and product presentation.
  JavaScript: Adds interactive features and user actions.

Project Files :
  index.html: Main webpage that contains the structure and content of the smartwatch landing page.
  style.css: Contains the styling rules for the webpage, including layout, fonts, colors, and product cards.
  script.js: Handles interactive functionality on the webpage.
  images/: Stores smartwatch product images and other visual assets, if included.
  README.md: Provides information about the project, technologies used, files, and instructions for running it.
  minor_project_03.zip: Compressed archive containing the project files.

  Note:
    The file descriptions above are a suggested structure. Update the Filenames and descriptions to match the actual contents of your project.

Features :
  Attractive smartwatch product presentation.
  Multiple smartwatch varieties.
  Simple and user-friendly interface.
  Interactive elements using JavaScript.
  Organized webpage layout.

How to Run the Project :
  Download the project repository.
  Extract the ZIP file on your computer.
  Open the project folder.
  Locate index.html.
  Open index.html in a web browser.

Learning Outcomes :
  Understanding HTML webpage structure.
  Applying CSS styling and layouts.
  Using JavaScript for basic interactions.
  Organizing and uploading project files to GitHub.
